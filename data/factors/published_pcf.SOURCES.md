## Lane and method

This lane's numbers come from documents producers and standards bodies
publish directly (PCFs, EPDs, association eco-profiles), not from a
queryable open database. Every value below was reached by downloading the
cited PDF (`urllib.request`, no `curl -o`) and reading it with
`pdftotext -layout` — never from a search-result snippet or an AI-generated
summary of the document. Where a document was found via web search but not
actually downloaded and read, it is listed under "Investigated, not
retrieved" and no number from it appears anywhere in this repo.

### 1-2. Benzene and Toluene

**Document**: PlasticsEurope & CEFIC/APPE, "Eco-profiles and Environmental
Product Declarations of the European Plastics Manufacturers — Benzene,
Toluene, and Xylenes (Aromatics, BTX)", February 2013. 46 pages.

**How it was reached**: `plasticseurope.org` itself returns HTTP 403 to a
direct fetch (confirmed live; matches the previous round's finding), and
even the Wayback Machine mirror of that domain is currently behind an
archive.org bot-challenge page (`sgcaptcha`) on this network — both dead
ends, consistent with the prior investigation's note. The working path was
`legacy.plasticseurope.org/en/resources/eco-profiles`: a Concrete5-era page
(HTTP 200, no bot gate) presenting an interactive flowchart. Its "toluene"
and "benzene" boxes carry a `/download_file/<id>/0` link; both point to the
same 15.75&nbsp;MB zip bundle (report PDF + EcoSpold/Excel/ILCD/Umberto
exports for benzene, toluene, o-xylene, p-xylene, and mixed xylenes).
- Toluene box → `https://legacy.plasticseurope.org/download_file/786/0`
- Benzene box → `https://legacy.plasticseurope.org/download_file/781/0`
- Verified reachable: yes, HTTP 200 (HEAD), both, 2026-08-27.

**Value and location**: Table 19 ("Global Warming Potential (GWP, 100
years) per 1 kg of product"), PDF page 32: Benzene 1.86, Toluene 1.22,
p-Xylene 1.43, o-Xylene 1.45, Mixed Xylenes 0.79 kg CO2 eq./kg. The same
figures are repeated in the front-matter "Environmental Performance /
Output Parameters" table on PDF page 4. Xylenes are not on this project's
target substance list and are not carried into the CSV, but are recorded
here since they came from the same document and the same read.

**Boundary**: explicitly "from cradle to gate (i.e. from crude oil
extraction to liquid BTX at plant)"; use phase and end-of-life explicitly
stated as outside the system boundary. Reference year 2010; data collection
2007–2010; report calculated/published February 2013. Characterisation:
IPCC 2007 (AR4) 100-year GWP, per the report's own "Climate Change" section.

**Not an ecoinvent/GaBi lookup — checked directly**: the report's own "Data
Sources and Allocation" section (PDF page 3) states: "The modelling of
steam cracking, catalytic reforming, and petroleum refinery is based on
confidential process and emission data from several sites... Representative
literature data have been used for the modelling of the extraction and
production of BTX from pygas and reformate." Data owner: "PlasticsEurope &
CEFIC/APPE"; number of plants: "50 steam cracker units; complemented by
desktop study of subsequent steps." This is primary industry data for the
foreground process, consistent with PlasticsEurope's own methodology
document (see below) — not a database characterization.

**Licence**: `legacy.plasticseurope.org/en/resources/eco-profiles` states,
in its own page body (fetched live): "This page enables free download and
use of PlasticsEurope's Eco-profiles." No further restriction is stated on
that page or inside the PDF itself (no copyright/reuse notice found by
`grep -i` over the extracted text for "copyright", "all rights",
"permission", "licence"/"license").

### 3. Dichloromethane (methylene chloride)

**Document**: Nobian Industrial Chemicals B.V., "Methylene Chloride ISCC
PLUS certified" Environmental Product Declaration, registration
`EPD-IES-0022304:001`, EPD International (environdec.com), published
2025-12-05, valid until 2030-10-20. LCA practitioner: EcoMatters
(jur.remeijn@ecomatters.nl et al.). 12 pages.

**How it was reached**: found via web search (`site:environdec.com`
queries), then the human-readable page
`https://www.environdec.com/library/epd22304` (HTTP 200) was fetched and
its embedded API call extracted:
`https://api.prod.environdec.com/api/v1/EPDLibrary/Files/EPDs/4a04bf22-a0fc-4ca2-6169-08dd7d87b4f5/Documents`,
which serves the EPD PDF directly (`Content-Type: application/pdf`).
Verified reachable: yes, HTTP 200 (GET; the endpoint rejects HEAD with
405 — the ingest script falls back to a small GET read for exactly this
case), 2026-08-27.

**Value and location**: Table 1 ("Global warming potential per kg of
methylene chloride"), PDF page 8, "Cradle to gate" column, row "GWP – total
(excl. biogenic)" = 4.80E-01 kg CO2-eq. This matches the report's own
headline sentence on the same page: "The cradle-to-gate carbon footprint
(excluding biogenic CO2-eq) is: 4.80E-01 CO2-eq / kg ISCC PLUS certified
methylene chloride." (The fossil-only row is 4.79E-01; the total-including-
biogenic row is 4.83E-01; this project uses the report's own declared
headline figure, 0.480 → rounded to 0.48 for the CSV.)

**Boundary**: declared unit "1 kg methylene chloride (dichloromethane,
CH2Cl2)". PCR Basic Chemicals 2021:03, v1.1.5, EN15804+A2 modules: A1
(upstream) + A2-A3 (core) = "Cradle to gate"; A4 (downstream transport to
customers, 0.0506 kgCO2e/kg) is reported as a separate column and is
**excluded** from the CSV value to keep it strictly at the plant gate.
Product: Frankfurt, Germany methane-chlorination plant; ISCC PLUS
mass-balance certified feedstock and renewable electricity input (a
book-and-claim renewable-electricity certification, noted here since it
affects how "renewable" should be read but does not change the declared
GWP boundary or figure).

**Licence**: EPD International AB, International EPD System, ISO
14025:2006 registered, independently third-party reviewed (PCR review by
the Technical Committee of the International EPD System). Publicly and
freely downloadable from the EPD Library for reference/citation use.

### 4-5. Hydrogen (steam reforming) and Ammonia

**Documents**: PlasticsEurope Eco-profiles "H2 reformer" and "Ammonia",
both authored by Ian Boustead for PlasticsEurope, "Data last calculated
March 2005". 12 pages each.

**How reached**: same `legacy.plasticseurope.org` flowchart as BTX above.
The flowchart's tooltip metadata (fetched live, embedded in the page HTML)
labels the two relevant boxes "Hydrogen (H2 reformer)" and "Ammonia"
respectively, both "Calc: 2005 / Process data: 2001 / 1 sites", and both
linked in the flowchart's own `data-relatives` graph to the same chlor-
alkali-independent hydrogen/ammonia production chain (i.e. this is the
steam-methane-reforming route feeding ammonia synthesis, not a chlor-alkali
or naphtha-cracker by-product route).
- Ammonia box → `https://legacy.plasticseurope.org/download_file/779/0`
- H2 reformer box → `https://legacy.plasticseurope.org/download_file/780/0`
- Verified reachable: yes, HTTP 200 (HEAD), both, 2026-08-27.

**Value and location**: each report's Table 7 ("Carbon dioxide equivalents
corresponding to the gross air emissions...") gives 20-year, 100-year and
500-year equivalent totals in mg per kg product. This project uses the
100-year row:
- Ammonia, PDF page 7-8: 100-year-equiv total = 2,400,000 mg = **2.4
  kgCO2e/kg**.
- Hydrogen (H2 reformer), PDF page 8: 100-year-equiv total = 7,500,000 mg =
  **7.5 kgCO2e/kg**.

Neither report restates which GWP characterisation set it used for this
table (it predates AR5/AR6; plausibly IPCC SAR/TAR-era, consistent with the
report's 2005 date) — recorded as a gap in the CSV `notes` rather than
guessed.

**Boundary**: cradle-to-gate production of 1 kg of product (natural-gas
steam reforming for hydrogen; steam-reforming hydrogen + air-separation
nitrogen for ammonia). Both reports are structured as raw LCI tables
(energy, raw materials, water, air emissions, water emissions, solid waste)
for production only — no use-phase or end-of-life tables are present in
either document, consistent with a cradle-to-gate scope.

**Not primary data by internal statement alone — corroborated externally**:
neither individual report states its own data-collection method inline
(no "Data Sources" section with plant counts, unlike the 2013 BTX report).
To avoid taking that on faith, PlasticsEurope's own methodology document —
"PlasticsEurope Eco-profiles programme and methodology V3.0" (fetched live,
`https://plasticseurope.org/wp-content/uploads/2021/12/PlasticsEurope-Ecoprofiles-program-and-methodology_V3.0.pdf`,
HTTP 200; this specific `/wp-content/uploads/` path is not behind the same
bot gate as `/en/resources/eco-profiles`) — was checked directly. It states
(p.~34): "In PlasticsEurope Eco-profiles programme, we aim at collecting
consistently the primary data of the foreground [processes]..." and
describes the standard method as "a spreadsheet-based questionnaire...
distributed to the participating member companies." It also confirms that
eco-profiles are the *source* feeding disaggregated versions into Ecoinvent
("in an adapted disaggregated form in database[s] like Ecoinvent"), not the
reverse — i.e. these are not database lookups presented as eco-profiles.

**A second hydrogen route exists and was deliberately not used**: the same
flowchart also has an "H2" box tied to naphtha steam-cracking (tooltip
"Hydrogen", download id 784, zip "PlasticsEurope H2 cracker Eco-profile
2005.pdf"). Its own Table 7, 100-year-equiv total = 1,700,000 mg = 1.7
kgCO2e/kg — a very different number, because this is by-product hydrogen
from a steam cracker with a different co-product allocation, not merchant/
dedicated hydrogen production. The steam-reformer route (7.5 kgCO2e/kg) was
judged the more representative "hydrogen" for a process-chemistry reagent
list (dedicated, on-purpose production, matched to the ammonia chain), and
using both under the same CAS in a single CSV would create a same-file
conflict against this project's own rules for how conflicts are supposed to
arise (between independent tables, not fabricated within one). The rejected
figure and its source
(`https://legacy.plasticseurope.org/download_file/784/0`) are recorded here
for anyone who wants to use the by-product-allocation number instead.

**Licence**: same page-level statement as BTX above ("This page enables
free download and use of PlasticsEurope's Eco-profiles").

## Re-verification

Run `PYTHONPATH=src python3 scripts/ingest_published_pcf.py --report` to
re-fetch every citation URL above and re-check every InChIKey against
PubChem live; it prints one line per row with reachability and PubChem
status and writes the same deterministic CSV. `--skip-pubchem` skips only
the PubChem step (useful offline); the HTTP reachability check always runs.
